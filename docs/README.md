# Documentation

Shroom's documentation currently contains ideas and one implementation proposal.
The proposal records the agreed direction and the runtime integration that still needs implementation and validation.

- [Minimal core proposal](proposals/minimal-core.md): a thin headless Rust layer over microsandbox,
  with guest SSH setup, access identity, connection details, and acceptance tests.
- [SSH-first coding workspaces](ideas/ssh-workspace-manager.md): product motivation and planned integrations.
- [Why Shroom works](ideas/why-shroom.md): naming and positioning.
